# 관리용 명령어

* 마법부여자 / 커인 슬롯 늘리는거\
  /ae giveitem \[닉네임] orb \[갯수] ARMOR \[단계] \[확률]\
  예) /ae giveitem yato\_3 orb 1 ARMOR 5 100
* 도감 와일드카드 지급 명령어\
  /와일드카드 NORMAL\_\[등급]\
  예> /와일드카드 NORMAL\_SS
* 아이템 이름 변경\
  /iname - 이름\
  /ilore \[add/set/clear] - 설명\
  [https://www.birdflop.com/resources/rgb/](https://www.birdflop.com/resources/rgb/)
* 커스텀 아이템 목록 - /ce
* 아이템 스킨 변경권 명령어 - /giveskin\
  /giveskin \[테마]:\[도구]\
  예) /giveskin mariposa\_requiem:shield
* ```
  스킨 목록
  eternal_god
  frostveil_genesis
  mariposa_requiem
  ruminite
  ```
