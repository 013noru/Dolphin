# ❗ 자주 사용하는 명령어

> **안내**: 인게임에서는 **`Shift + F`** 또는 **`/메뉴`** 입력으로 대부분의 기능을 GUI에서 원클릭으로 이용할 수 있습니다.

---

## 🏃 기본 · 이동 · 보상 · 편의 명령어

| 명령어 | 단축키 / 별칭 | 기능 설명 |
| :--- | :--- | :--- |
| **`/메뉴`** | `Shift + F` | 서버 종합 메뉴 GUI 열기 |
| **`/길라잡이`** | `/guidance` | 32단계 초보자 성장 가이드 및 보상 확인 |
| **`/스폰`** / **`/서버`** | `/spawn` · `/server` | 중앙 스폰 이동 / 다른 채널·서버 이동 |
| **`/집 설정 [이름]`** / **`/집 [이름]`** | `/sethome` · `/home` | 개인 거점 지정 및 텔레포트 |
| **`/tpa [닉]`** / **`/tpaccept`** | - | 유저 간 텔레포트 요청 및 수락 |
| **`/추천`** / **`/우편함`** / **`/쿠폰`** | `/vote` · `/mailbox` · `/coupon` | 서버 추천, 우편 수령, 이벤트 쿠폰 등록 |
| **`/가방`** / **`/유틸리티`** | `/vc` · `/util` | 크로스 서버 가상 창고 / 랭크 자동 편의 토글 |
| **`/필터등록`** / **`/갑옷숨기기`** / **`/쓰레기통`** | `/filteradd` · `/ha` · `/tr` | 잡템 자동 소멸 필터 / 갑옷 투명화 / 휴대용 쓰레기통 |
