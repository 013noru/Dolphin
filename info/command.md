# ❗ 자주 사용하는 명령어

> **안내**: 돌고래 서버에서 자주 사용되는 핵심 명령어 모음입니다.  
> 인게임에서는 **`Shift + F`** 또는 **`/메뉴`**를 입력하시면 대부분의 기능을 GUI 창에서 원클릭으로 이용하실 수 있습니다.

---

> 📷 **[사진으로 표시: `/메뉴` 실행 시 열리는 전체 메인 GUI 창 캡쳐]**

---

## 🏃 기본 및 이동 명령어

| 명령어 | 단축키 / 별칭 | 기능 설명 |
| :--- | :--- | :--- |
| `/메뉴` | `Shift + F` | 서버 종합 메뉴 GUI를 엽니다. |
| `/스폰` | `/spawn` | 서버 중앙 스폰 광장으로 이동합니다. |
| `/집 설정 [이름]` | `/sethome [이름]` | 현재 서 있는 위치를 내 집으로 지정합니다. |
| `/집 [이름]` | `/home [이름]` | 지정한 집으로 즉시 텔레포트합니다. |
| `/tpa [닉네임]` | - | 대상 플레이어에게 텔레포트 요청을 보냅니다. |
| `/tpaccept` | - | 받은 텔레포트 요청을 수락합니다. |
| `/서버` | `/server` | 다른 채널이나 전용 서버로 이동합니다. |

---

## 🪙 경제 및 거래 명령어

| 명령어 | 단축키 / 별칭 | 기능 설명 |
| :--- | :--- | :--- |
| `/돈` | `/bal`, `/money` | 내가 보유한 코인(돈) 잔액을 확인합니다. |
| `/송금 [닉네임] [금액]` | `/pay` | 대상 유저에게 실시간으로 안전하게 돈을 송금합니다. |
| `/상점` | `/shop` | 서버 공식 상점을 엽니다. |
| `/판매` | - | 현재 손에 들고 있는 아이템을 즉시 일괄 판매합니다. |
| `/경매장` | `/ah` | 글로벌 유저 비대면 경매장을 엽니다. |
| `/ah sell [가격]` | `/판매 [가격]` | 손에 든 물품을 경매장에 등록 판매합니다. |

---

## 💼 직업 & 스탯 관련 명령어

| 명령어 | 기능 설명 |
| :--- | :--- |
| `/직업` | 직업 종합 메뉴를 열어 생활직/전문직 정보를 확인합니다. |
| `/직업경험치` | 각 직업별 현재 경험치 및 보상 획득 확률을 확인합니다. |
| `/스탯` | 레벨업으로 획득한 능력치 포인트를 배분합니다. |
| `/도감` | 수집 도감 창을 열어 아이템을 납품합니다. |
| `/물고기도감` | 낚시로 획득한 커스텀 물고기 전용 도감을 엽니다. |

---

## 🏰 마을(토지) 명령어

| 명령어 | 기능 설명 |
| :--- | :--- |
| `/마을` | 마을(영토) 관리 GUI 창을 엽니다. |
| `/마을 생성 [이름]` | 새로운 마을을 창설하고 첫 영토를 확보합니다. |
| `/마을 주장` | 현재 서 있는 청크를 내 마을 영토로 확장 점유합니다. |
| `/마을 초대 [닉네임]` | 다른 유저를 내 마을의 주민으로 초대합니다. |
