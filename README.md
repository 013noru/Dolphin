# 🐬 돌고래 서버 공식 가이드북

> **환영합니다!**  
> 돌고래 서버는 풍성한 **4대 생활 직업**과 **4대 전문 직업**, 탄탄한 경제 시스템 및 마을(토지) 커뮤니티를 기반으로 하는 **고품격 경제 반야생 서버**입니다.  
> 본 위키는 처음 시작하는 신규 유저부터 숙련된 모험가까지 필요한 모든 시스템과 규칙을 쉽게 찾아볼 수 있도록 제작되었습니다.

## 🧭 초보자 빠른 정착 4단계 가이드

서버에 처음 접속하셨다면 아래 순서대로 확인하시면 가장 빠르게 적응하실 수 있습니다.

```
[1. 서버 규정 확인] ➔ [2. 튜토리얼 & 길라잡이] ➔ [3. 직업 선택] ➔ [4. 경제 & 마을 정착]
```

1. **[📒 서버 규정 확인](info/rule.md)**: 안전하고 즐거운 플레이를 위해 기본 매너와 벌점 기준을 확인하세요.
2. **[🧭 튜토리얼 & 길라잡이](guide/02..md)**: 스폰 탈출 방법과 초보자 지원 퀘스트인 길라잡이를 확인하세요.
3. **[💼 직업 선택](guide/06..md)**: 파밍할 때마다 돈과 경험치가 쌓이는 생활 직업과 강력한 장비를 만드는 전문 직업을 살펴보세요.
4. **[🪙 경제 명령어](guide/03-1/README.md) & [🏰 마을 시스템](guide/04..md)**: 번 돈으로 상점/경매장을 이용하고, 나만의 영토(마을)를 만들어 집을 안전하게 보호하세요.

## 🔍 원하는 정보를 빠르게 찾는 법 (위키 검색)

원하시는 시스템, 아이템, 명령어는 위키 상단의 **검색창**을 활용하시면 즉시 찾으실 수 있습니다.

* **데스크톱(PC) 화면**: 상단 검색창을 클릭하거나 단축키 `Ctrl + K` (또는 `/`)를 누르세요.
  <figure><img src=".gitbook/assets/image (3).png" alt="데스크톱 검색"><figcaption>데스크톱 검색창 위치</figcaption></figure>

* **모바일 화면**: 우측 상단의 돋보기 아이콘을 터치하여 검색어를 입력하세요.
  <figure><img src=".gitbook/assets/image (4).png" alt="모바일 검색"><figcaption>모바일 돋보기 아이콘 위치</figcaption></figure>
