# Util

* 유틸리티(편의성) 기능은 `[/util]` 명령어를 입력하시면 GUI 창에서 켜고 끌 수 있습니다.
* **👑 VIP 회원 특권**: VIP를 보유하신 경우 랭크 승급 조건과 무관하게 5대 유틸리티 전체를 즉시 무제한 사용하실 수 있습니다.

---

### 자동 줍기 (AutoPickup)

* **산호(CORAL) 등급** 이상 사용 가능 (총합 150Lv)
* 활성화 시 블록을 캐거나 몬스터를 처치해 습득한 아이템이 바닥에 떨어지지 않고 인벤토리로 자동으로 들어옵니다.

### 자동 조합 (AutoCraft)

* **골드(GOLD) 등급** 이상 사용 가능 (총합 300Lv)
* 활성화 시 습득한 아이템이 인벤토리 내에서 자동으로 조합됩니다.
* 아이템 4~9개를 모아 블록으로 만들 수 있는 광물/작물 등이 자동으로 압축 조합됩니다.

### 자동 심기 (AutoReplant)

* **에메랄드(EMERALD) 등급** 이상 사용 가능 (총합 500Lv)
* 활성화 시 농작물을 수확할 때 인벤토리에 씨앗이 있다면 수확한 자리에 즉시 자동으로 다시 심어줍니다.
* 나무의 맨 밑동 원목을 벨 때도 인벤토리의 해당 묘목을 소모해 자동으로 묘목을 심어줍니다.

### 작물 보호 (CropProtect)

* **에메랄드(EMERALD) 등급** 이상 사용 가능 (총합 500Lv)
* 다 자라지 않은 미성숙 작물을 실수로 캐거나 부수지 않도록 완벽히 방지합니다.
* 수박/호박 줄기는 영구적으로 보호되며, 밭을 갈아엎으려면 `Shift + 좌클릭`으로 강제 파괴할 수 있습니다.

---

### 📦 원격 유틸리티

* **조합대**: 어디서든 가상 작업대 창을 즉시 엽니다. (`/조합대`, `/wb`)
* **엔더 상자**: 보관함으로 복귀하지 않고 어디서든 개인 엔더 상자를 즉시 엽니다. (`/엔더상자`, `/ec`)
* **모루**: 설치형 모루 없이 가상 모루 창을 즉시 엽니다. (`/모루`, `/anvil`)
