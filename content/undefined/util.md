# Util

* 유틸리티(편의성) 기능은 \[/util] 명령어를 입력하시면 킬 수 있습니다.
* VIP를 소유하신 경우 해당 조건에 맞지 않아도 사용 가능합니다.

### 자동 줍기

* CORAL 등급이 되면 사용 가능합니다.
* 활성화 시 습득한 아이템이 자동으로 인벤토리에 들어옵니다.

### 자동 조합

*
* 활성화 시 습득한 아이템이 자동으로 조합됩니다. \
  아이템 4\~9개를 모아 블록으로 만들수 있는 거의 모든 아이템이 조합됩니다.

### 자동 심기

*
* 활성화 시 농작물을 수확할 때 인벤토리에 씨앗이 있다면 자동으로 다시 심어줍니다.

### 작물 보호

*
* 전부 자라지 않은 작물을 실수로 캐지 않게 방지합니다.
* 줄기류는 자동으로 보호됩니다.
