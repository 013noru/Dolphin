## 1. 🪙 5대 서버 공식 화폐 & 잔액 확인

| 화폐 명칭 | 명령어 (단축) | 주요 획득처 및 사용처 |
| :--- | :--- | :--- |
| **🪙 코인 (기본 돈)** | `/money` (`/돈`, `/bal`, `/코인`) | 상점·경매장·강화·랭크·마을 등 서버 모든 기본 경제 활동 기축통화 |
| **💎 캐시** | `/cash` (`/캐시`) | 후원·대형 이벤트를 통해 획득, 특수 캐시 상점 및 치장 구매 |
| **🎖️ 마일리지** | `/mileage` (`/마일리지`) | 일일 플레이타임 보상(1h·2h·4h 각 100 지급), 전용 마일리지 상점 교환 |

## 2. 💸 송금 · 랭킹 · 종이 수표 · 경험치 책 · 가상 창고

<figure><img src="../../.gitbook/assets/1028_renewal/expbook_all.png" alt="경험치 책 발급 및 사용 GUI"><figcaption></figcaption></figure>

| 기능 | 명령어 (사용 형식) | 핵심 동작 및 규칙 |
| :--- | :--- | :--- |
| **부자 랭킹** | `/돈순위 [페이지]` | 전 서버 실시간 코인 보유 순위표 열람 *(미입력 시 1페이지)* |
| **실시간 안전 송금** | `/pay <닉> <금액>` (`/지불`, `/돈 송금`)<br>`/캐시 보내기 <닉> <금액>` (`/cash pay`) | • 칭호·한글 닉/영문 ID 자동 식별 & 크로스 서버 즉시 송금<br>• 오프라인·없는 유저·본인 입력 시 **100% 자동 환불**, 보유액 초과/0 이하 차단 |
| **종이 수표** | `/수표 <금액> [수량]` (`/cheque`) | • **최소 10,000원** *(Tab 자동완성: 1만/3만/5만/10만)* · 최대 64장 동시 발급 & 스택<br>• **우클릭** 1장 입금 / **`Shift + 우클릭`** 뭉치 전체 일괄 입금 |
| **경험치 조회·책** | `/경험치량` (`/exp`)<br>`/경험치책 <량> [수량]` · `최대`/`max` | • 정확한 누적 바닐라 EXP 조회 및 거래 가능한 책 추출(**최소 100 EXP**, 최대 64권)<br>• **우클릭** 1권 사용 / **`Shift + 우클릭`** 책 뭉치 일괄 흡수 |
| **가상 창고** | `/가방` (`/vc`, `/rkqkd`) | • **크로스 서버 실시간 동기화** 개인 창고 (채널·월드 이동 시 유지)<br>• 기본 1페이지 ➔ `가상창고 쿠폰` 우클릭 시 **최대 14페이지(756슬롯)** 확장 |
