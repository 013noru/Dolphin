## 2. 🛠️ 랭크 해금 유틸리티 (`/유틸리티`) & 휴대용 가상 도구

<figure><img src="../.gitbook/assets/1028_renewal/util.png" alt="유틸리티 설정 GUI"><figcaption></figcaption></figure>

### ① 🌟 5대 핵심 유틸리티 (`/유틸리티`, `/유틸`, `/util`)

| 편의 기능 | 해금 등급 | 상세 동작 및 참고 |
| :--- | :---: | :--- |
| **자동 줍기** | 산호 (150Lv) | 채굴·사냥 드롭 아이템을 인벤토리에 즉시 자동 수납 *(여유 공간 없을 시 바닥 드롭)* |
| **전리품 가방** | 산호 (150Lv) | 지정 전리품을 무제한급 가상 창고에 자동 적립 · **`/전리품가방`** (`/lootbag`)으로 꺼내기 |
| **자동 조합** | 골드 (300Lv) | 광물·작물 9개 자동 블록/바구니 변환 + 커스텀 작물 자동 연쇄 승급 *(일반2➔은별2➔금별4➔보라별)* |
| **자동 심기** | 에메랄드 (500Lv) | 수확·벌목 시 인벤토리의 씨앗·묘목을 소모해 그 자리에 즉시 자동 재식립 |
| **작물 보호** | 에메랄드 (500Lv) | 미성숙 작물·줄기 실수 파괴 방지 · *(밭을 갈아엎을 때는 **`Shift + 좌클릭`**)* |

### ② 🧰 휴대용 가상 도구 & 원격 보관함

| 기능 | 명령어 / 조작법 | 해금 등급 | 설명 |
| :--- | :--- | :---: | :--- |
| **가상 작업대** | `/작업대` (`/ct`, `/craft`) | 산호 | 어디서나 3×3 작업대 열기 |
| **가상 엔더상자** | `/엔더` (`/ender`, `/엔더상자`) | 산호 | 어디서나 개인 엔더상자 열기 |
| **가상 모루** | `/모루` (`/anvil`) | 산호 | 어디서나 모루 수리·결합 창 열기 |
| **원격 셜커 오픈** | 손에 들고 **`Shift + 좌클릭`** | 사파이어 | 바닥 설치 없이 27칸 셜커 상자 즉시 열기 |
