## 1. 🪨 특수 작업대 및 핵심 설비 (`xxxlpack` & `default`)

마을 또는 개인 거점에 설치하여 고급 전문직 활동 및 가공을 진행하는 설비 목록입니다.

{% tabs %}
{% tab title="커스텀 양조기" %}
### 커스텀 양조기 (`brewing_stand`)
* **제작 방식**: 형태 조합 (`shaped`)
* **필요 재료**: 바닐라 `양조기` 1개 + `엔드 수정` 2개
* **조합 배치**: 상단과 하단에 엔드 수정 각 1개, 정중앙에 바닐라 양조기 1개 배치
* **특징**: 연료 소모 없이 연금술사 전용 특수 포션을 제조하는 전문 작업대입니다.
{% endtab %}

{% tab title="커스텀 마법부여대" %}
### 커스텀 마법부여대 (`enchanter_table`)
* **제작 방식**: 형태 조합 (`shaped`)
* **필요 재료**: 바닐라 `마법부여대` 1개 + `네더라이트 주괴` 2개
* **조합 배치**: 바닐라 마법부여대와 네더라이트 주괴 2개를 조합
* **특징**: 마법부여사 전용 연성대 및 마나 과충전 미니게임을 진행하는 설비입니다.
{% endtab %}

{% tab title="주괴 금형 틀" %}
### 주괴 금형 틀 (`ingot_mold`)
* **분류**: 특수 영구 촉매틀
* **특징**: 커스텀 대장기술(합금) 혼합물 배합 시 작업창에 함께 올려 사용하는 필수 금형입니다. **조합 시 소모되지 않고 영구적으로 유지**됩니다.
{% endtab %}

{% tab title="네더라이트 모루" %}
### 네더라이트 모루 (`netherite_anvil`)
* **제작 방식**: 형태 조합 (`shaped`)
* **필요 재료**: `네더라이트 블록` + `네더라이트 주괴`
* **특징**: 기존 철 모루보다 내구도가 월등히 높고 견고한 최상위 모루 설비입니다.
{% endtab %}
{% endtabs %}
