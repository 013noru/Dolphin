## 1. ⏱️ 접속 시간 보상 (⚠️ 당일 추천 필수!)

서버에 접속해 있는 시간(30분, 1시간, 2시간, 4시간)마다 단계별 접속 보상이 지급됩니다.
* **⚠️ 필수 수령 조건**: **오늘 서버 추천(Vote)**을 완료한 유저만 접속 시간 보상과 우편함 보상을 수령할 수 있습니다!
* 추천을 완료하면 밤 12시(자정) 초기화 전까지 모든 접속 시간 보상을 마음껏 챙길 수 있습니다.

---

## 2. ⭐ 서버 추천(투표) & 연속 추천 보너스 (`/추천`)

서버에 투표하여 서버 랭킹을 올려주고 엄청난 혜택을 받으세요!

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/vote** | `/추천` | 서버 추천(투표) | 서버 추천 링크를 확인하고, 1~7일 연속 추천 보상(자정 1~3등 선착순 열쇠)을 받습니다. |

* **연속 추천(Streak) 보상**: 1일차부터 7일차까지 하루도 빠짐없이 매일 연속으로 추천하면 날마다 더 좋은 보상을 순환 지급합니다!
* **👑 자정(00:00) 선착순 열쇠**: 매일 밤 12시 자정이 되자마자 1등, 2등, 3등으로 추천을 누른 유저 3명에게는 초희귀 전설 열쇠가 선착순으로 지급됩니다!

## 3. 📫 멀티서버 통합 우편함 (`/우편함`)

운영자 지원금, 이벤트 보상, 쿠폰 보상은 모두 내 개인 우편함으로 배달됩니다!

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/mailbox** | `/우편함`, `/dnvusgka` | 개인 우편함 | 운영자 지원금, 이벤트 보상, 쿠폰 보상이 도착하는 우편함을 엽니다 (당일 추천 완료 필수). |

<이미지> *(우편함 보관함 GUI 화면)*
* 서버에 접속했을 때 우편이 도착해 있으면 채팅창에 알림이 뜹니다.
* 우편함에서 원하는 편지를 클릭하여 인벤토리로 안전하게 수령하세요.

## 4. 🎟️ 이벤트 쿠폰 사용하기 (`/쿠폰`)

디스코드나 공지사항에 공개된 이벤트 쿠폰 코드를 입력해 보상을 받으세요!

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/coupon <코드>** | `/쿠폰 <코드>` | 이벤트 쿠폰 등록 | 이벤트 쿠폰 코드를 입력하여 우편함으로 보상을 즉시 발송받습니다. |

* 등록된 쿠폰 코드를 입력하면 즉시 내 **우편함(`/우편함`)**으로 아이템이 안전하게 배송됩니다.

---

## 5. 📦 랜덤박스 (가챠 상자 미리보기 & 개봉)

서버에서 획득한 다양한 등급의 랜덤박스 상자입니다.
* **좌클릭 (미리보기)**: 상자를 열기 전에 **[좌클릭]**하면 어떤 아이템들이 몇 % 확률로 들어있는지 **구성품 미리보기 GUI**가 열립니다! <이미지>
* **우클릭 (개봉)**: 상자를 열고 싶을 때 **[우클릭]**하면 화려한 가챠 연출과 함께 당첨된 아이템을 획득합니다.
