## 1. 🌟 5대 핵심 유틸리티 (`/유틸리티` - 자유 토글)

채팅창에 **`/유틸리티`** (또는 `/유틸`, `/utility`)를 입력하면 5가지 편의 기능을 언제든 자유롭게 켜고 끌(On/Off) 수 있는 설정 창이 열립니다.  
각 유틸리티 기능은 서버 랭크 승급을 통해 단계별로 해금됩니다.

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/utility** | `/유틸리티`, `/유틸`, `/dbxlf` | 5대 유틸 설정 | 자동 줍기, 자동 조합, 자동 심기, 작물 보호, 전리품 가방 토글 창을 엽니다. |

## 2. 🛡️ 토글 필요 없는 상시 자동 보호 시스템 (100% 상시 적용)

> 💡 **안내**: 아래 보호 기능들은 유저가 명령어로 **따로 켜거나 끌 필요가 없습니다(토글 불필요).**  
> 서버에 접속한 모든 플레이어에게 **24시간 100% 무조건 상시 자동 적용**되는 절대 안전장치입니다!

### ① 🛡️ 도구 내구도 1 보호 시스템 (영구 파괴 방지)
* **작동 원리**: 벌목, 연쇄채광, 광역 수확 등으로 도구의 내구도가 급격하게 소모되더라도, **내구도가 딱 `1`이 되는 순간 도구가 절대 깨지지 않고 사용이 즉시 멈춥니다!**
* **실수 방지 안전장치**: 내구도가 1이 된 상태에서는 실수로 허공이나 땅에 휘둘러 아이템이 깨지는 사고를 막기 위해 **채굴/공격 행동이 자동으로 차단**되며 화면에 안전 경고 알림이 뜹니다.
* **대처법**: 도구가 깨지지 않고 안전하게 보존되었으므로, 안심하고 **대장간 수리 시스템(전용 망치 또는 수리 키트)**으로 수리하여 영구적으로 계속 쓰시면 됩니다!

### ② ⛓️ 귀속 저주(Curse of Binding) 자동 영구 해제
* **작동 원리**: 바닐라 마인크래프트에서 실수로 `귀속 저주`가 걸린 갑옷을 입으면 죽기 전까지 벗지 못하는 대참사가 일어납니다.
* **서버 전용 보호**: 서버에서는 귀속 저주가 걸린 갑옷을 손에 들거나 착용하려 할 때, **귀속 저주 인챈트가 흔적도 없이 100% 즉시 자동 삭제**됩니다!
* 따라서 저주 장비에 갇힐 걱정 없이 안전하고 자유롭게 장비를 갈아입으실 수 있습니다.

## 3. 🎒 인벤토리 절약 & 필터 꿀기능

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/filteradd** | `/필터등록`, `/차단등록` | 잡템 차단 등록 | 손에 들고 있는 아이템을 등록하여 획득 시 즉시 자동 소멸시킵니다. |
| **/filterlist** | `/필터목록` | 차단 목록 확인 | 차단 등록한 아이템 목록을 GUI로 확인하고 클릭하여 해제합니다. |
| **/filterclear** | `/필터초기화` | 차단 필터 초기화 | 등록된 모든 아이템 필터를 한 번에 초기화합니다. |
| **/lootbag** | `/전리품가방` | 전리품 가방 열기 | 광물, 작물 등 지정 전리품이 자동 적립되는 무제한급 가상 창고를 엽니다. |

### ① 잡템 자동 소멸 필터 (`/필터등록`)
광질이나 사냥할 때 조약돌, 썩은 살점, 안산암 같은 잡템이 인벤토리를 어지럽히는 게 싫다면?
* 버리고 싶은 아이템을 손에 쥐고 **`/필터등록`**을 입력하면 획득 시 즉시 자동 소멸합니다!

### ② 전리품 가방 (`/전리품가방`)
* 채광이나 채집 중 획득한 광물과 기본 아이템들이 인벤토리를 차지하지 않고 가상 전리품 가방에 안전하게 차곡차곡 쌓입니다. 필요할 때 GUI를 열어 원하는 만큼 꺼낼 수 있습니다.

### ③ 셜커 상자 바닥에 안 깔고 열기 (`Shift + 좌클릭`)
* 셜커 상자를 손에 든 상태에서 **`Shift(웅크리기) + 허공/바닥 좌클릭`**!
* 셜커 상자를 굳이 바닥에 설치할 필요 없이 손에 든 채로 즉시 27칸 창고가 시원하게 열립니다. (VIP 회원 전용 특권)

## 4. 👗 치장 및 옷차림 편의 기능 (갑옷 투명화)

| 명령어 | alias | 기능 | 설명 |
| :--- | :--- | :--- | :--- |
| **/ha** | `/갑옷숨기기` | 갑옷 외형 투명화 | 방어력/효과는 유지한 채 갑옷 외형만 투명하게 숨기거나 다시 보이게 토글합니다. |

### ① 갑옷 투명화 (`/갑옷숨기기` 또는 `/ha`)
* 착용 중인 강력한 다이아/네더라이트 갑옷의 방어력과 인챈트 효과는 그대로 유지한 채, **외형만 완벽하게 투명하게 숨겨 내 예쁜 스킨을 그대로 보여줍니다.** (튜토리얼부터 누구나 무료 사용 가능, 다시 입력 시 해제)
* 새 갑옷으로 갈아입거나 서버를 이동해도 투명 상태가 안전하게 유지됩니다!
